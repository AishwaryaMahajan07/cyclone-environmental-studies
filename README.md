# Cyclones & Their Impacts — CHE 110 Environmental Studies

Academic visual research website by **Aishwarya Mahajan** and **Sukhnaj Kaur**, Lovely Professional University.

## Files
- `index.html` — complete website
- `style.css` — academic environmental-study design
- `script.js` — mobile navigation and small interactions

## Publishing
Upload all files to a GitHub repository and enable GitHub Pages from the repository's Settings → Pages. The site uses remote official/public-domain image URLs so an internet connection is required to display those images.

## Sources represented in the website
- Lovely Professional University official Media Kit for the LPU logo.
- India Meteorological Department (IMD), *Orissa Super Cyclone – A Synopsis*.
- NOAA satellite imagery of Cyclone 05B (1999), public domain via Wikimedia Commons.
- NASA/SeaWiFS imagery of the 1999 Odisha cyclone, public domain via Wikimedia Commons.
